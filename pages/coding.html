A short list of places worth your time. Pick one language, build small things, and move on when the tutorials stop teaching you anything.

How to progress

  • Pick one language. Python or JavaScript, then stay with it for a month.
  • Practise deliberately. Small problems every day beat a ten-hour binge.
  • Build. A calculator, a notes app, a tiny API — finish things.
  • Read code. Open-source projects teach more than another course.
