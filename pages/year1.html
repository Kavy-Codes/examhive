First-year resources

Maintained by Kavycodes · checked by the health script

First year is mostly foundations. Keep the material small, do the problem sets, and build one thing with what you learn.

What is here

  • Core subjects — maths, physics, chemistry and introductory programming notes.
  • Reference books — use one good book per subject, not five PDFs you never open.
  • Coding practice — start with the coding page once you know one language.
  • Projects — small builds beat a folder of tutorials.
